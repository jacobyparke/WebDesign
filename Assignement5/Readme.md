Component Plan
Webpage component applied to
Mood Board / Image Marquee + Heading font
Type of component
Image gallery and horizontally scrolling mood board with hovering heading letters
Why needed
The mood board gives the website a visual way to show images that represent the style and inspiration of Kobe Kolor. 
Using Flexbox helps keep the images organized in one horizontal row while allowing the section to work across
different screen sizes. The effect on the heading gives it more life instead of uniform horozontal motion.
Features
Multiple image cards displayed in a horizontal row
Consistent spacing between images
Rounded image cards
Horizontally scrolling animation
Responsive sizing for smaller screens
Images remain organized and easy to view
What you’ll use to build it
Flexbox
