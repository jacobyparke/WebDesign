Which consistent colors, values, lines, and/or shapes did you utilize and why?

2. I started a gradient fading color backdrop from the beginning. With Assignment 4, I added descending dew drops to this backdrop

Which Google Fonts did you use and for what purposes?

3. I chose "Ole" for my website headings because I like the curliness of the font and it looks good with added shadowing, almost like
   a smokey quality. I would like to change my headings to a more liquid, chrome, font effect in the future. I also used two variations
   of sans serif (Georgia and Seoul) because they both feel classic and legible.
